# Puzzle Dungeons

Puzzle Dungeons is a 2D puzzle dungeon game built with Godot.

The player explores dungeon levels, solves puzzles, and interacts with the environment to find a way through each level.

The game is built around grid-based movement and tile-based dungeon layouts, with a focus on carefully designed puzzles and progressively more challenging levels.

## Development

The game is currently in early prototype development.
